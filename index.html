💪 실천 제안

📱 스마트 사용법

  1. 하루 2시간 이내 (황금 시간대)
  2. 공부 시 폰 격리
  3. 잠자기 1시간 전 폰 OFF
  4. 앱 타이머 설정

⏰ 시간 관리

  1. 포모도로 기법 (25분 집중 + 5분 휴식)
  2. 할 일 완료 후 SNS
  3. 친구와 함께 도전

• 인과관계: 상관관계 ≠ 인과관계
